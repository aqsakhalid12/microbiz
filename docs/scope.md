# Scope

## In-scope (v1 features)

1. Register / login / logout
2. Business profile and settings
3. Dashboard
4. Products CRUD with search/filter
5. Customers and order history
6. Multi-item orders
7. Order status: Pending / Confirmed / Processing / Completed / Cancelled
8. Payment status: Unpaid / Partially Paid / Paid
9. Expenses with categories
10. Date-filtered reports
11. Low-stock alerts and inventory movement history
12. Optional product images

## Out-of-scope

- Online payments
- Shipping integrations
- Customer-facing registration or storefront
- Frontend frameworks (vanilla JS only)
